- View the optimal layout for the page depending on their device's screen size
- See hover and focus states for all interactive elements on the page
- Open and close the navigation menu at any screen size (optional JavaScript)

### What I learned

Improved my CSS a lot more than when I first started out. Got the chance to practice and improve CSS grid and flexbox. I was wary of CSS grid before starting this project but as I got more familiar with it, I began to realise that it gives the developer a lot more room to play with. 

### Continued development

Will continue to learn and impliment CSS in a more effective and professional way. I couldn't get the entire page to fit the screen without the use of a scroll bar. So I will try to find the solution and update this code later.

### Useful resources

Lots of Youtube videos, books, web docs and AI tools helped with understanding some aspects of applying CSS. These resources helped me to update my current knowledge and to look at some CSS properties in a new perspective. 

### AI Collaboration

I used chatgpt and gemini to understand some tricky aspects of CSS. I was able to practice on small projects suggested by those AI tools to strengthen my understanding before tackling this project.
